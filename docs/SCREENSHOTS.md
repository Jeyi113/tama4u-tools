# 스크린샷 촬영 가이드

포트폴리오/README용 스크린샷 4장. 각 장면은 아래 순서대로 만들면 그대로 재현된다.

```bash
python3 -m tama4u edit          # http://127.0.0.1:8477
```

촬영은 macOS 기준 `Cmd+Shift+4` → 스페이스바 → 창 클릭 (창 단위 캡처),
또는 `screencapture -iw docs/01-editor.png`.

브라우저 창은 **1280×720 이상**으로 두면 2열 레이아웃이 유지된다.

| 파일명 | 장면 | 만드는 법 |
|---|---|---|
| `01-editor.png` | 아이템 편집 기본 화면 | `4u-download-pack/meals/cup-noodles-meal.jpg` 열기 |
| `02-character.png` | 캐릭터 내장 액세서리 합성 14쌍 + 착용 좌표 편집 | 캐릭터 파일(`fk00002_1-kururutchi.jpg`) 열고 **↳ 옷장 패킷** 선택 → "내장 액세서리 합성" 섹션 |
| `03-id-version.png` | iD 펌웨어 버전 변환 + 기종 변환 카드 | iD Lovely Melody 액세서리(`FlowerHairBand_LMv.JPG`) 열기 → 좌측 하단 |
| `04-nested.png` | 중첩 패킷 (외출지 + 보상 아이템 4개) | `4u-download-pack/outings/chubu-outing.jpg` 열기 |

## 각 장면에서 보여줄 것

- **01** — 좌측: 이름/시리얼/가격/만복도·행선지·5스탯, 우측: 24×24 스프라이트 3장 탭 +
  픽셀 에디터 + 팔레트 + BMP 입출력
- **02** — 포즈+액세서리 14쌍이 각각 X/Y 좌표 입력칸과 함께. 타일을 드래그하면
  1px 스냅으로 좌표가 바뀐다는 점이 핵심
- **03** — 호불호 그리드가 iD에서 **11칸**으로 줄어든 것,
  "이 버전으로 변환" 버튼과 로스터 경고문, 기종 변환 버튼 3개(iD 액세서리는 비활성)
- **04** — 좌측 패킷 목록에 중첩 구조(`↳`)와 각 보상 아이템,
  우측에 128×72 외출지 배경 스프라이트
